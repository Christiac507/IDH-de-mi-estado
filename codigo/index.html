¿Qué es el Índice de Desarrollo Humano?

El Índice de Desarrollo Humano (IDH) es una medida del Programa de las Naciones Unidas para el Desarrollo (PNUD) que resume en un valor de 0 a 1 el nivel de bienestar de una población. Mientras más cerca de 1, mayor es el desarrollo humano. Se calcula a partir de tres dimensiones básicas:

❤️ SaludVivir una vida larga y saludable.
📚 EducaciónAdquirir conocimientos.
💰 IngresoTener un nivel de vida digno.
Aquí aparecerá la información del IDH de la entidad seleccionada.
Datos: PNUD México, Índice de Desarrollo Humano para las entidades federativas, México 2015 (datos de 2012).
